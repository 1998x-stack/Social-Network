项目是 Newman《Networks》一书的配套工程，按 5 大部分 / 19 章组织：

- 124 个节 `.py` 文件，但全部为 7 行空壳（仅头注释 + docstring）。
- `main.py`（264 行）：一个生成器脚本，根据 `structure` 字典创建目录、空壳文件与 README 索引。

目标：将代码库提升为专业水准——共享核心库 + 日志 + 测试 + 可视化 + 富文档，并建立可扩展到 124 节的模板化流程。

## 4. 架构：项目布局

**关键约束**：节的文件名（如 `7.7_介数中心性.py`）因含点号与中文字符而**无法导入**为 Python 模块。因此它们保持为**独立可运行脚本**，导入共享的可导入核心包 `netlab`。这样兼得选项 2 + 3 的好处，且不违背 Python 导入规则。

```
Social-Network/                          # 仓库根目录 (git)
├── pyproject.toml                       # 元数据、依赖、工具配置 (pytest, ruff, mypy)
├── README.md                            # 重新生成 + 精修的索引
├── netlab/                              # ★ 共享可导入核心包
│   ├── __init__.py                      # 版本 + 公共 API 复导出
│   ├── logging_setup.py                 # 结构化日志配置辅助
│   ├── plotting.py                      # 图形工厂、样式/保存辅助
│   ├── graph_utils.py                   # 共享图/验证工具
│   └── demos.py                         # run(key) 驱动任意节
├── docs/
│   └── sections/                        # 富 per-section .md，镜像章节树
├── tests/                               # pytest 树，镜像章节树
│   ├── conftest.py                      # 共享 fixtures + 节加载器
│   └── ...
└── 第Ⅰ部分_网络的实证研究/.../7.7_介数中心性.py   # 节保持可运行，import netlab
```

### 每节脚本模式（统一）

- 头注释 + 节标识（标准化）
- docstring + 参数/返回值约定
- 一个或多个**纯函数**（导入时无副作用）：`compute_x(...)`、`simulate_y(...)`
- 经由 `netlab.plotting` 产生该节图件的可视化函数
- `if __name__ == "__main__":` 块 — 运行演示并输出 `outputs/<section>/`：日志、结果、PNG

### 测试用的节加载器

因文件名不可导入，`tests/conftest.py` 提供 `load_section(path_or_key)`（`importlib.util.spec_from_file_location`），使任何测试都能读到节函数，无论中文/带点文件名。

## 5. 日志

使用标准库 `logging`，经 `netlab.logging_setup` 配置：

- 每节的 `__main__` 调用 `setup_logging(level=INFO, logfile=..., structured=False)`。
- **结构化记录格式**：时间戳、节键、运行类型、关键指标，如 `[2024-08-17 10:12:03] [7.3∣run] Katz: 5 nodes, α=0.1, done in 0.0021s`。摒弃旧的 `print`。
- 日志同时写入 stdout 与 `outputs/<section>/run.log`；纯函数通过模块 logger 记录，必要时否则返回值。
- 级别约定：`INFO`=demo 进度；`DEBUG`=算法内部；`WARNING`=边界情况（不连通图、空度序列、发散）。

## 6. 测试（pytest）

- `tests/` 镜像节树，每节一个 `test_<section>.py`。
- **与参考交叉验证**：断言手写结果与 networkx 内建一致（容差内）。
- **性质/不变量测试**（如 BA 度序列、SIR S+I+R 守恒、拉普拉斯 L·1=0）。
- **确定性**：固定随机种子；回归测试锁定数值输出。
- **边界测试**：空/单节点/单一连通分量图抛出清晰、已记录的错误。
- `conftest.py` 提供 `load_section()` + 共享 fixture（已知小图、默认种子、容差常量）。覆盖率通过 pytest-cov 追踪。

## 7. 可视化

集中到 `netlab.plotting`，统一样式：

- **样式预设**：图尺寸、调色板、网格样式、中文字体回退（PingFang/Noto）、紧凑布局、300dpi。经 `netlab.plotting.configure()` 应用一次。
- **图形工厂** `new_figure(...)`：设置图 id、标题（含节键）、轴标签。
- **保存约定** `save_fig(fig, key, name, dpi)` → `outputs/<section>/<name>_<size>dpi.png`（+ 最富图 `.pdf`），供文档引用。
- 每节可视化函数可接收 `ax` 或返回路径，保持轻薄、可测试（CI 中 `matplotlib.use("Agg")`）。

**试点对应的可视化类型**：
- 中心性 → 条形图 / 网络布局，节点大小 ∝ 分数
- BFS → 按距离/顺序着色 + 路径高亮
- BA → 度分布对数-对数图，叠加理论指数
- SIR → S/I/R 时间序列（+ 相图）
- 拉普拉斯 → 特征值谱 + 按 Fiedler 向量着色的 spring 布局
