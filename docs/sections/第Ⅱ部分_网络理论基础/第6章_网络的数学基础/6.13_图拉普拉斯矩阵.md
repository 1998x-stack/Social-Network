# 6.13 图拉普拉斯矩阵

## 概述

图拉普拉斯矩阵 $L = D - A$ 把图的拓扑编码进一个对称半正定矩阵，是谱图论、谱划分、扩散过程与图神经网络的基础。其谱（特征值）与网络的结构特性——连通性、社团、扩散时间尺度——紧密相关。

## 核心概念与公式

$$ L = D - A $$

- $D$：度对角矩阵 $D_{ii} = \deg(i)$。
- 性质：$L\mathbf{1} = 0$（最小特征值为 0）；特征值 0 的代数重数 = 连通分量个数；第二小特征值（**Fiedler 值**）> 0 当且仅当图连通，其值反映连通"强度"。
- 对应 Fiedler 向量常用于把图分割为两个社团（谱划分）。

## 代码说明

- `laplacian(adj)`：返回 $L = D - A$。
- `fiedler(evals)`：返回第二小特征值。
- `viz(adj)`：绘制特征值谱 + 按 Fiedler 向量着色的 spring 布局。
