# 17.3 SIR模型

## 概述

SIR 模型将人群分为易感（Susceptible）、感染（Infectious）、康复（Recovered）三类，是研究传染病在人群中传播的经典框架。这里实现基于个体随机状态的模拟，观察疫情如何爆发、达到峰值并最终消退。

## 核心概念与公式

微分方程形式：
$$ \frac{dS}{dt} = -\beta SI,\quad \frac{dI}{dt} = \beta SI - \gamma I,\quad \frac{dR}{dt} = \gamma I $$

- $\beta$：传染率（单位时间每个 I 感染 S 的强度）。
- $\gamma$：康复率（单位时间 I 康复的比例）。
- 基本再生数 $R_0 = \beta / \gamma$：>1 才会出现大爆发。

## 代码说明

- `sir_simulate(pop, beta, gamma, t_max, i0=1, seed=42)`：随机模拟，返回 `(t, S, I, R)`，保证 $S+I+R=$ 人口数守恒。
- `viz(t, S, I, R)`：绘制 S/I/R 时间序列。
