# 14.2 Barabási-Albert模型

## 概述

Barabási-Albert（BA）模型揭示了现实网络「无标度」的成因：优先连接。新加入的节点更倾向连接到已有的高度数节点（富人更富），从而产生幂律（长尾）度分布 $P(k) \sim k^{-\gamma}$，$\gamma$ 常接近 3。它解释了万维网、引文网络等为什么高度不均匀。

## 核心概念与公式

- 初始 $m_0$ 个节点构成完全图。
- 每步新增 1 个节点，连 $m$ 条边，连接到节点 $i$ 的概率与其度成正比：
  $$ \Pi_i = \frac{k_i}{\sum_j k_j} $$
- 稳态度分布 $P(k) \sim k^{-\gamma}$，$\gamma = 3$（连续平均场近似）。

## 代码说明

- `barabasi_albert(m0, m, n, seed)`：手写优先连接（用 `random.Random` 加权重采样），避免重边/自环。
- `degree_distribution(G)`：返回 (度值, 频率)。
- `viz(G)`：对数-对数度分布图，附幂律参考线。
